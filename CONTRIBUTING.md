# Web Empresa CI/CD

Proyecto ficticio utilizado para establecer un flujo de trabajo
de versionamiento y despliegue continuo.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Actions
- GitHub Pages

## Ramas

- main: versión estable y de producción.
- develop: integración de nuevas funciones.
- feature/*: desarrollo de características.

## Flujo

feature/* -> develop -> main

Los cambios se integran utilizando Pull Requests.
